# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/your-username/python-for-data-engineering.git

cd python-for-data-engineering
```

## Run a Python Program

```bash
python 01-python-fundamentals/05-lists/list_basics.py
```

For Linux/macOS:

```bash
python3 01-python-fundamentals/05-lists/list_basics.py
```

---

## Requirements

- Python 3.10+
- No third-party packages required for current examples

Verify your installation:

```bash
python --version
```
