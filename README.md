# Python for Data Engineering 🐍

A beginner-friendly repository documenting my journey of learning Python with a focus on building the foundation required for Data Engineering.

## 🎯 Goal

Learn Python step by step, write clean and readable code, and gradually apply these skills to data engineering concepts and projects.

## 📚 Topics Covered

- Print Function (`main.py`)
- Literals (`test.py`)
- Number Systems (`test(1).py`)
- Type Conversion (`test(1).py`)
- Operators & Expressions (`test(2).py`)

> More topics will be added as the learning journey progresses.

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone <your-repository-url>
cd python-for-data-engineering
```

### Run a Python File

```bash
python main.py
```

If required, use:

```bash
python3 main.py
```
